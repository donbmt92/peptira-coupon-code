# Keyword and intent analysis

Research date: 2026-11-12 (Asia/Saigon context)

## Scope

The target phrases are “peptira coupon code,” “peptira promo code,” “peptira discount code,” and “peptira discount history.” No search-volume, difficulty, traffic, revenue, commission, or ranking figures were available, so none are estimated.

## Observed intent

The current Google result page for the primary phrase was transactional: most visible results promised a current code or discount. The history query was less well served. It still returned coupon pages and inconsistent historical claims rather than a transparent, versioned dataset.

This repository can match a secondary, evidence-checking intent if it focuses on:

- dated observations instead of “always current” claims;
- exact source evidence and explicit expiry/uncertainty;
- machine-readable history and strict validation;
- reproducible discount arithmetic;
- separation of publisher verification from independent checkout verification.

It should not compete by repeating affiliate landing-page copy or claiming that an untested code works.

## Repository-format fit

No GitHub repository appeared among the first visible organic results inspected for the primary query. That means repository format is not proven to match the dominant transactional intent. A repository is nevertheless useful for developers, researchers, and auditors who want structured history and calculation code. Organic performance is an assumption to test, not an expected outcome.

## Content decision

Proceed, because the project remains useful with all affiliate links removed: the JSON records, schema validator, stale/expiry checks, tests, and sequential calculator still function. Keep only one disclosed Peptigator reference link in the README.

## Validation hypotheses

1. Search engines may index a factual README for long-tail “discount history” or verification-related queries.
2. Users may value the arithmetic explanation when stacked percentages are advertised additively.
3. A GitHub README may underperform coupon pages for “coupon code” intent.

These hypotheses require Search Console and repository referral data after publication; they are not findings.
