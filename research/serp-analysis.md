# SERP analysis

Observed on 2026-11-12 through a read-only Google browser session from Vietnam. The interface language was Vietnamese. Results are location-, language-, time-, device-, and personalization-dependent.

## “peptira coupon code”

The page displayed an AI Overview and coupon-focused organic results. Visible publishers included SimplyCodes, Peptide Dosing Protocols, StartupWorld, Reddit, and Prof. Peptide. Claims conflicted: snippets referenced SAVE10, HARLAN, PROFPEPTIDE, and different discount levels. No GitHub repository was visible in the inspected first page.

Interpretation: dominant intent is to find a code quickly. A repository should not imitate a coupon landing page; it can serve verification, provenance, and calculation needs.

## “peptira discount history”

The results still emphasized coupon pages, with inconsistent claims about baseline and seasonal discount levels. No clear first-page, versioned historical offer dataset was visible. Some results appeared unrelated or low quality.

Interpretation: there may be an information gap for an evidence-led historical ledger, but the observation does not establish meaningful search demand.

## Limitations

- Direct Google result URLs were inaccessible to the search connector, so a browser session was used.
- Only the primary and history variants were inspected directly on Google. The external search index also returned results for the promo-code variant.
- No paid SEO tool or Search Console data was available.
- Google AI Overview statements were not accepted as factual offer evidence.
- Rankings, volumes, difficulty, traffic, and commissions are intentionally not reported.
